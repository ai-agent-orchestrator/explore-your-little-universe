# Lumi 타로 카드 아트 · GPT 프롬프트와 개발 인계

2026-11-23 · 사용자가 ChatGPT에서 제작하고 선택한 이미지 원본을 보관한다.

## 확정 구성

대표 카드 **Hermit → Tower → Star**는 탐색 → 변화 → 회복이라는 전시 순서다. 실제 뽑기 순서나 고정 스프레드를 뜻하지 않는다. 톱니 장식과 Lumi가 있는 커스텀 앞면 3장, 공통 뒷면 1장을 사용한다.

| 파일 | 카드 | 사용자 원본 파일명 |
| --- | --- | --- |
| `images/tarot/hermit.png` | 은둔자 · IX | 별빛을 밝히는 은둔자의 여정-1.png |
| `images/tarot/tower.png` | 탑 · XVI | 업보의 붕괴_ 빛나는 탑 타워.png |
| `images/tarot/star.png` | 별 · XVII | 카르마의 공명과 별빛 물결.png |
| `images/tarot/back.png` | 공통 뒷면 | 카르믹 공명의 별자리 타로 카드.png |

나머지 앞면 **75장**은 파일별 이용 조건을 확인한 라이더–웨이트–스미스(RWS) 원본 도상으로 추가한다. 현대 채색판 Universal Waite와 혼동하지 않는다. RWS 원본 75장은 아직 이 저장소에 추가되지 않았다.

출처 후보: https://commons.wikimedia.org/wiki/Category:Rider-Waite_tarot_deck

개별 파일의 출처 페이지·작가·판본·라이선스 표시·가져온 날짜를 기록한다. 사용자 생성 커스텀 이미지를 RWS 퍼블릭 도메인 이미지로 표시하지 않는다.

## GPT 공통 앞면 프롬프트

다음 공통 지시와 카드별 지시를 합쳐 한 장씩 생성한다. 아래는 재제작용 프롬프트이며 실제 생성 당시 입력의 완전한 기록은 아니다. 최종 선택 이미지가 외형 기준이다.

```text
웹앱 Explore Your Little Universe의 Lumi 타로 앞면 한 장을 만들어줘.
세로 2:3, 1024×1536, 정면 평면 일러스트. 카드 전체로 화면을 채워줘.
미드나이트 네이비 우주, 보라색 성운, 따뜻한 금빛, 섬세한 동화적 일러스트.
얇은 이중 금색 테두리와 별자리 선, 오른쪽 위와 왼쪽 아래에 보라·금색 톱니 장식.
작은 미소 짓는 별 친구 Lumi를 보조 캐릭터로 넣어줘.
톱니는 여러 에이전트의 협력과 우주의 연결을 상징하며 주인공을 가리지 않게 해줘.
선택한 기존 카드 이미지를 첨부하면 테두리, 채색, 밀도, Lumi 외형을 맞춰줘.
카드명과 숫자는 앱에서 표시하므로 넣지 말고, 목업·손·책상·외부 그림자는 제외해줘.
이번 카드의 장면은 아래 설명을 따라줘.
```

### Hermit — 탐색

```text
망토를 두른 인물이 고요한 산길에서 별빛 등불과 지팡이를 들고 있다.
등불은 바로 앞 몇 걸음을 따뜻하게 비춘다. Lumi가 길 옆을 함께 떠다닌다.
밤하늘과 초승달, 금빛 식물 장식. 사색, 자기 속도, 내면의 지혜를 표현한다.
```

### Tower — 변화

```text
별빛 우주의 돌탑에 금빛 번개가 닿아 균열 사이로 빛이 드러난다.
탑을 감싸는 빛의 리본에 모래시계·책·끊어지는 사슬·새싹 상징을 담는다.
Lumi가 옆에서 지켜본다. 익숙한 구조의 변화와 새 가능성을 표현한다.
부상이나 추락 장면 없이 상징적으로 표현한다.
```

### Star — 회복

```text
단정한 흰옷과 남보라 망토를 입은 인물이 두 물병으로 물과 땅에 물을 붓는다.
큰 금빛 별과 작은 별들이 하늘에 빛나고 Lumi가 옆에 떠 있다.
맑은 물결, 새싹, 작은 꽃으로 회복과 희망, 균형을 표현한다.
```

## GPT 공통 뒷면 프롬프트

```text
Explore Your Little Universe의 타로 공통 뒷면 한 장을 만들어줘.
Lumi의 따뜻한 우주와 Multi-Agent Orchestrator의 협력 구조를 천체 지도로 표현해줘.
세로 2:3, 1024×1536, 정면 평면 디자인, 불투명 배경.
중앙의 금빛 Lumi 별을 큰 톱니가 감싸고, 주변 여덟 개의 보라·청록색 톱니 노드가
금빛 궤도와 연결선으로 중앙 및 서로 연결된다. 각 노드에는 별·궤도·기하학 문양을 넣어줘.
네이비 우주와 보라 성운, 금빛 이중 테두리, 마주 보는 초승달과 작은 별을 배치해줘.
중앙 리본에는 Karmic Resonance라는 문구를 넣어줘.
따뜻하고 정교하며 앞면 세 장과 같은 시리즈로 보여야 해.
기계 회로도·로봇·실물 목업·손·책상·워터마크는 제외해줘.
```

현재 선택된 뒷면에는 정방향 문구가 있어 완전한 180도 회전대칭은 아니다. 정역방향을 미리 숨기는 기능에 사용할 경우, 뒷면 표시 방향을 고정하고 앞면 공개 시점에 저장된 방향을 적용한다. 완전 회전대칭 버전을 추가 제작하려면 중앙 문구를 없애고 모든 장식·빛·별을 180도 회전쌍으로 배치하도록 요청한다.

## 개발자 연결 작업

- 앞면은 총 78장: 커스텀 3장 + RWS 75장. 공통 뒷면은 별도 1장.
- 카드 카탈로그의 안정된 카드 ID와 이미지 경로를 명시적으로 매핑한다. 파일명에서 임의 추론하지 않는다.
- 역방향 이미지를 따로 만들지 않고 앞면을 화면에서 180도 회전한다. 카드명·방향·위치 UI는 읽을 수 있게 유지한다.
- 원본 PNG는 이 경로에 보존한다. 앱용 경량 이미지가 필요하면 별도 파생 파일로 만들고 원본을 덮어쓰지 않는다.
- 현재 이미지는 README 전시 자산이다. 서버·카드 뽑기·리딩 기능이 구현됐다는 의미가 아니다.
